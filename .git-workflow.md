# Git Branch Workflow - Quick Reference

## Current Setup ✅

- **Repository**: https://github.com/zymer4him2024/aiodcounterdemo.git
- **Main Branch**: `main` (production stable)
- **Feature Branch**: `feature/hourly-aggregates` (for testing)

## Quick Commands

### View Current Status
```bash
git status              # See current branch and changes
git branch              # List all branches
git log --oneline -5    # See recent commits
```

### Switch Branches
```bash
git checkout main                           # Switch to production
git checkout feature/hourly-aggregates      # Switch to feature branch
git checkout -b feature/new-feature-name    # Create and switch to new branch
```

### Make Changes
```bash
# On feature branch
git add .                                    # Stage changes
git commit -m "Description of changes"       # Commit changes
git push                                     # Push to GitHub
```

### Deploy to Staging
```bash
# Make sure you're on feature branch
git checkout feature/hourly-aggregates

# Deploy to staging
firebase use staging
npm run build
firebase deploy --only hosting,functions,firestore
```

### Merge to Production
```bash
# 1. Switch to main
git checkout main
git pull origin main

# 2. Merge feature
git merge feature/hourly-aggregates

# 3. Push to GitHub
git push origin main

# 4. Deploy to production
firebase use production
npm run build
firebase deploy --only hosting,functions,firestore

# 5. Clean up
git branch -d feature/hourly-aggregates
git push origin --delete feature/hourly-aggregates
```

## Important Notes

1. **Always start from main**: `git checkout main && git pull` before creating new branches
2. **Test on staging first**: Never deploy directly to production from feature branches
3. **Commit frequently**: Small, descriptive commits are better than large ones
4. **Push feature branches**: Keep your work backed up on GitHub

## Troubleshooting

### Undo uncommitted changes
```bash
git checkout -- .        # Discard all uncommitted changes
git reset HEAD .         # Unstage all files
```

### See differences
```bash
git diff                                    # See uncommitted changes
git diff main..feature/hourly-aggregates   # Compare branches
```

### Stash changes (temporary save)
```bash
git stash              # Save changes temporarily
git checkout main      # Switch branches
git checkout feature/hourly-aggregates
git stash pop          # Restore changes
```
